Este será un proyecto test

Una web estática que documenta una prueba de la Agentic Factory.

El proyecto

Es una página simple en HTML y CSS, publicada en GitHub Pages, que sirve para probar de punta a punta el flujo de construir software con agentes.

La factory

La Agentic Factory es un sistema donde agentes con roles distintos (planificador, constructor) toman issues de GitHub, escriben código y tests, y publican los cambios.

Cómo se probó

  1. Idea: se definió el producto.
  2. Issue: se planeó la arquitectura y el backlog como issues.
  3. Agentes: cada issue lo implementó un agente con tests en verde.
  4. Despliegue: la página se publica en GitHub Pages.
